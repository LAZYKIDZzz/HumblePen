# 笔记内容规范

[English](en/content-format.md)

## 选择与合并

记录用户实际提问、可复用的专业知识。一个知识点使用一个长期稳定的编号。写作前按问题、术语和命令检索既有条目。对同一主题的追问补充原条目，修正错误时保留经过脱敏的修正说明。纯执行请求、业务进度、项目实装、缺少复用价值的排查流水账直接跳过。答案缺失或冲突时标为 **待确认**，只保留已知事实。

新增编号从两种语言当前的最大编号加一，至少补齐三位。并行运行可能选到同一个编号，建议一个仓库同一时间只运行一个整理任务。合并前重新核对主分支和编号。

## 笔记与每日摘要

笔记路径为 `docs/skills/SK-NNN.md`。第一行标题、分类、关键词及日期格式如下：

```markdown
# SK-005｜查询示例工具版本

分类：命令行；关键词：版本、命令行。

首次记录：2026-01-02；最近补充：2026-01-02；最近复习：2026-01-02

**问题：** 怎样确认正在使用的命令行工具版本？

## 答案与示例

先查看该工具文档支持的版本参数，例如 `example-cli --version`。

## 适用条件

适用于示例工具明确提供版本参数的情况。

来源：2026-01-02，虚构问答示例。
```

首次记录日期固定。实质补充才更新最近补充日期，实际复习才更新最近复习日期。新建时以记录日期初始化三个字段。需要时增加「修正历史」，写明日期和脱敏后的改动原因。

在 `docs/个人技能记录清单.md` 登记新条目。实际新增或补充的知识在 `daily/YYYY-MM-DD.md` 用相对链接引用，例如 `[SK-005 查询示例工具版本](../docs/skills/SK-005.md)`。补跑按来源日期归入原摘要；同一输入重跑不重复条目、来源和更新记录。导航和搜索索引由构建生成。

同一知识点的中英文笔记共用编号。英文版放在 `en/docs/skills/`，更新英文清单 `en/docs/skill-index.md` 和英文日摘要 `en/daily/`。各语言摘要引用同语言笔记。只整理一种语言时，可以独立更新。两种笔记的字段格式分别见本页和英文版。

## 脱敏与渲染

用 `/path/to/file.txt`、`example.com`、`user@example.com`、`192.0.2.10` 或 `<TOKEN>` 替代实际环境值。路径、业务数据、标识、聊天链接和来源对应关系一起移除。案例对象应泛化，能定位它的漏洞编号、仓库地址、包名或配置名也要检查。示例保留命令结构和适用边界。来源只写日期和泛化说明。

笔记使用普通 Markdown。代码放进普通围栏代码块，标记语言如 `sh`、`json`、`html`。笔记校验限制活动 HTML、Vue 表达式、图片、前置元数据和文件嵌入。完成后运行 `npm run check`，并逐条语义审阅内容。
