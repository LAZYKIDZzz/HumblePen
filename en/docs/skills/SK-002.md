# SK-002 | Validate and pretty-print JSON

Category: Data formats | Keywords: JSON, indentation, Python, json.tool.

First recorded: 2026-01-01 | Last updated: 2026-01-01 | Last reviewed: 2026-01-01

**Question:** With Python available, how can I check that a file contains valid JSON and format it for reading?

## Answer and example

`python3 -m json.tool` parses the file and writes indented JSON to standard output. It leaves the input file intact. If parsing fails, the command returns a nonzero exit status and reports the location of the error.

```sh
python3 -m json.tool /path/to/example.json
```

## When to use it

This command requires Python 3 and checks JSON syntax. Validate field structure, types, and business constraints separately.
