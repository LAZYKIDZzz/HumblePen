# SK-001 | Show line numbers when searching text

Category: Command line | Keywords: grep, line numbers, fixed strings.

First recorded: 2026-01-01 | Last updated: 2026-01-01 | Last reviewed: 2026-01-01

**Question:** How do I search a log for a literal string and see the line number of each match?

## Answer and example

`grep -n` shows line numbers starting at 1. Add `-F` to treat the search pattern as a fixed string, so a dot matches a literal dot.

```sh
grep -nF -- 'check.ready' /path/to/example.log
```

The output `12:check.ready` means the match is on line 12.

## When to use it

Use fixed-string matching when you know the exact text to find. Use regular expression matching when you need to describe several possible forms of a match.
