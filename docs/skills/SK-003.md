# SK-003｜用 GitHub Pages 发布公开知识库

分类：部署示例；关键词：GitHub Pages、GitHub Actions、VitePress、公开部署。

首次记录：2026-11-11；最近补充：2026-11-11；最近复习：2026-11-11

**问题：** 怎样把 HumblePen 发布到 GitHub Pages，并让读者直接打开和搜索站内笔记？

## 答案与示例

1. 从模板创建公开仓库，默认分支用 `main`。
2. 打开仓库 **Settings → Pages**，将 **Build and deployment → Source** 设为 **GitHub Actions**。
3. 在 **Settings → Secrets and variables → Actions → Variables** 新建仓库变量 `PAGES_ENABLED`，值填 `true`。
4. 在 **Actions → Publish public GitHub Pages** 选择 **Run workflow**，使用 `main`。以后推送到 `main` 会触发发布。
5. 通过 Pages 设置里的站点链接打开首页，从顶部「部署示例」点回本页，再直接刷新，确认深层地址可访问。搜索「固定文字」并打开结果，检查搜索链接也能正常跳转。分享本页时复制浏览器地址即可。

工作流从 GitHub Pages 取得站点基础路径，验证构建后只上传 `.vitepress/dist`。默认仓库子路径和自定义域名根路径共用同一份站点配置。配置自定义域名后重新运行发布。Pull Request 由校验工作流检查构建。

要暂停更新，移除变量或改成 `false`。要停止访问已有站点，在 Pages 设置中取消发布。

## 适用条件

用于可以公开阅读的内容。公开仓库中的笔记和提交历史，以及网站的页面数据和搜索索引都可公开访问。首次推送前审阅整个仓库。需要按账号限制阅读权限时，参阅[私有服务器部署示例](./SK-004.md)。
