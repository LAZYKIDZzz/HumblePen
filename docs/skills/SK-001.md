# SK-001｜查找文本时怎样显示行号

分类：命令行；关键词：grep、行号、固定字符串。

首次记录：2026-01-01；最近补充：2026-01-01；最近复习：2026-01-01

**问题：** 怎样在示例日志里查找固定文字，并显示匹配所在的行号？

## 答案与示例

`grep -n` 显示从 1 开始的行号。`-F` 把模式当作普通字符串，避免把点号等字符解释成正则元字符。

```sh
grep -nF -- 'check.ready' /path/to/example.log
```

例如输出 `12:check.ready`，说明示例文本的第 12 行匹配。

## 适用条件

适合查找已知的固定文字。需要用正则描述多个可能的匹配形式时，选择对应的正则模式。
