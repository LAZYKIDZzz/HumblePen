# SK-002｜JSON 缩进检查与输出

分类：数据格式；关键词：JSON、缩进、Python、json.tool。

首次记录：2026-01-01；最近补充：2026-01-01；最近复习：2026-01-01

**问题：** 手边只有 Python 时，怎样检查示例文件是不是有效 JSON，并得到便于阅读的输出？

## 答案与示例

`python3 -m json.tool` 解析文件并将缩进后的 JSON 打印到标准输出。源文件保持原样。解析失败时，命令返回非零状态并报告错误位置。

```sh
python3 -m json.tool /path/to/example.json
```

## 适用条件

需要 Python 3。这一步验证 JSON 语法。字段结构、类型和业务约束需要另外验证。
